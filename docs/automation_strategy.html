Purpose & Scope

What this programme proves, and what it deliberately leaves out

Purpose

Give the business a trustworthy, repeatable signal that the UK Credit Memo AI behaves correctly — grounded, cited, fast and safe — before every release.

  • Correct retrieval of UK standards for real credit questions.
  • Answers grounded in retrieved context, with UK citations.
  • Robust extraction across PDF, image and text memos.
  • Consistent UK-readiness scoring with evidence.
  • Working UI and enforced release gates.

Scope

In scope (automation report): functional, BDD, UI automation, integration/E2E, regression, release gates and AI-specific checks — 85 cases.

Out of scope (kept in the codebase): developer-owned unit tests (test_units.py, unit marker). They run with pytest -q but are excluded from the automation report via -m "not unit".

This keeps the report meaningful for automation testers and respects the developers' ownership of unit tests.

Evaluation Checks

A 100-question golden dataset scored end-to-end, offline and deterministically

The golden dataset

100 UK questions with a gold document and expected keywords each: 35 core credit & regulatory, 35 affordability / IFRS 9 / conduct / financial crime, 30 paraphrases and UK-ised covenants & policy.

Per-question rows are stored so regressions can be diffed run over run.

Retrieval & generation metrics

  • Retrieval: Recall@5, Precision@5, MRR, Hit@5
  • Generation: Faithfulness, Hallucination, Answer relevance, Correctness
  • Performance: p50 and p95 latency per query

Entry / Exit Criteria & Risk

When the suite may run, and when a release may ship

Entry criteria

  • Dependencies installed; Tesseract present for OCR tests.
  • UK knowledge base present (uk_*.txt).
  • Evaluation report generated before the gate tests.

Exit criteria

  • All 85 automation cases pass.
  • Evaluation verdict is PASS.
  • Recall ≥ .90, Faith ≥ .90, Rel ≥ .90, Hall ≤ .05, p95 ≤ 3s.
  • Any failing gate blocks the release.

Key risks & mitigations

  • OCR missing → skip guards + actionable errors.
  • Lexical metrics → tuned UK synonyms + conservative gates.
  • Paraphrase recall → paraphrase bank + metamorphic tests.
  • Unit leakage → marker + filter + a test that asserts exclusion.
